# Changelog

All notable changes. Versions follow `MAJOR.MINOR.PATCH`; the model version is `__version__` in `src/<package>/__init__.py` and is written into `results/results.json`.

## 0.2.0 - 2026-11-05
- Single script split into a package: `synth.py` (generator), `pipeline.py` (training, evaluation, bootstrap, ablation, economics), `figures.py`.
- Parameters (seed, intensity, split, approval reference, LGD, margin, bootstrap size) moved into `data/params.json`; results are stamped with the model version.
- Added tests on the split, leakage canary, headline definition, bootstrap interval and a slow end-to-end reproduction test.
- Dataset documented (`data/DATA_DICTIONARY.md`) with a 2,000-row sample; full data regenerated on demand.
- Figures generated by `make figures`; paper numbers come from `results/results.json`.
- Fixed cross-reference numbers of figures in the paper.

## 0.1.0 - 2026-11-04
- First HTML presentation and Python script.
