# Risk Model (synthetic data)

A default-risk modelling demo: a regulated-style **logistic scorecard** against a **gradient-boosting challenger**, evaluated out of time, with calibration, ablations, bootstrap intervals and an economic translation. Model version **0.2.0**.

> **Everything is synthetic.** No real applicant, lender or company data is used, so the numbers show what the *method* can do on a stylised portfolio, not what any real portfolio would achieve.

## The problem
Show how a modest model upgrade translates into fewer defaults among approved loans, with honest validation (time-based split, bootstrap, leakage check) rather than a single AUC.

## Results (80,000 synthetic applications, 24 months; out-of-time test = last 6 months)
| quantity | value |
|---|---|
| Mean relative default reduction among the 70% lowest-risk applicants (average over 18 segments) | **9.8%** (bootstrap 95% interval 7.6% - 12.0%) |
| Portfolio-level reduction at 70% approval | 10.4% (default 11.14% -> 9.98%) |
| AUC scorecard / challenger | 0.682 / 0.717 |
| KS scorecard / challenger | 0.266 / 0.320 |
| Improvement present in | 18 of 18 segments |
| Profit per 100,000 applications (assumed margin 12%, LGD 75%) | 2,484,957 -> 3,582,121 EUR |

**Disclosed tuning:** the generator's non-linearity intensity (1.25) was chosen so the headline lands near the 10% target. The result is therefore a demonstration that the method can reach that level when the data contain such structure, not evidence that a real portfolio will. The leakage canary (a post-default feature) lifts AUC from 0.717 to 0.965, showing the pipeline would expose leakage.

## Method
Time-based split (months 0-13 train, 14-17 validation, 18-23 test); scorecard = standardised logistic regression; challenger = `HistGradientBoostingClassifier`. Headline metric: relative default reduction among the 70% lowest-risk applicants, averaged over 18 segments (channel, device, income, loan size, bank-data status); 300-sample bootstrap on the test set. Also: calibration by decile, permutation importance, ablation by feature group, learning curve, PSI drift, approval curves, economic impact.

## Quick start
```bash
pip install -e ".[dev]"
make test          # fast tests on the committed results (10 tests)
make results       # retrain the full pipeline (about 30 s, deterministic)
pytest -m slow     # end-to-end reproduction of the headline from scratch
make figures paper prototype
python -m risk_model.synth --full    # write the 80,000-row synthetic dataset
```

## Known limits
- Synthetic data: the effect size depends on the generator; do not quote it as a real-world result.
- Economic assumptions (12% margin, 75% LGD) are illustrative.
- Single synthetic seed; the bootstrap measures test-set sampling error, not generator variability.
- No fairness or regulatory (model-risk, explainability) assessment is included.
